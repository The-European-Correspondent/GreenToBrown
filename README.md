# GreenToBrown
Analysing Satellite imagery to find changes in land colour

### Overview of files

You need to download the output folder to allow 002/003/004 to work properly. The output folder contains the processed satellite images. To download the satellite images yourself, you will need to run 001 first.

* 001 - Contains the main code for processing satellite images and downloading them from Google Earth Engine.
* 002 - Contains the code for generating and mapping average color
* 003 - Contains the code for generating and mapping browness and greenness
* 004 - Contains the code for generating and mapping vegetation health - this isnt working yet
